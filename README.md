# FORGE FITNESS

A modern fitness consultation and trainer booking website designed for personal trainers and fitness businesses.

FORGE FITNESS helps fitness professionals showcase their services, manage consultation availability, and receive booking requests through a dedicated trainer dashboard.

## 🚀 Features

* Modern and responsive fitness website
* Trainer profiles and consultation services
* Consultation booking form
* Trainer availability management
* Dedicated trainer dashboard
* Supabase database integration
* Booking confirmation email integration using Resend
* Booking and consultation management

## 🛠️ Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend & Database: Supabase
* Email Service: Resend
* Deployment: Netlify

## ⚙️ Setup

1. Clone the repository.
2. Open the project folder.
3. Configure the required Supabase environment settings.
4. Run the website using a local development server.
5. Configure the Supabase Edge Function and Resend email service separately.

## 🔐 Environment Variables

Required environment variables should be configured securely.

Never expose private API keys, service-role keys, or email service secrets in frontend code or public repositories.

FORGE FITNESS is a portfolio project demonstrating the development of a functional business website with consultation booking, availability management, database integration, and email notifications.
